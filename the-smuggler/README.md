# THE SMUGGLER (نسخة السيرفر)

لعبة bullet-hell ثلاث مراحل. اللي بيهزم البوس بياخذ صورة الكأس من السيرفر.

## ليش ما في طريقة تاخذ الصورة بدون ما تلعب؟

- **الصورة مش موجودة باللعبة أبداً.** محفوظة على السيرفر بس، ومشفّرة بـ AES-256-GCM. المفتاح جاي من `SMUGGLER_SECRET`، يعني الكود المنشور لحاله ما بيفيد.
- **العشوائية بتنعطى لحظة بلحظة بسرعة الوقت الحقيقي.** هاي أهم حماية. رصاص الزعيم لكل إطار هو كتلة تشفير (AES-CTR) مفتاحها عند السيرفر بس. المتصفح لازم يطلب العشوائية من السيرفر نافذة نافذة عبر `/api/rng`، والسيرفر ما بيفتح النافذة الجاية إلا لما تثبت — بتسجيلك لحد الآن — إنك **عشت** الإطارات السابقة وبوقت حقيقي. يعني:
  - **ما حدا يقدر يحسب جولة فوز مسبقاً** (العشوائية كلها مش موجودة قبل).
  - **ولا يقدر يجمعها كلها الأول ويحلها بعدين** (العشوائية المتأخرة بتضل مقفولة لحد ما تعيش الإطارات اللي قبلها فعلاً).
  هاد بالضبط بيكسر الطريقتين اللي انحلّت فيهم قبل.
- **السيرفر ما بيصدّق المتصفح.** بيعيد تشغيل تسجيلك كامل بنفس الكود (`public/sim.js`)، وما بيبعث الصورة إلا إذا الزعيم مات فعلاً.
- **كل محاولة جلسة مستقلة** بتذكرة موقّعة (HMAC)، وعشوائيتها خاصة فيها، فما بتقدر تعيد تسجيل من محاولة ثانية.
- **الغش بالمتصفح ما بيفيد.** تعديل صحة الزعيم أو الخلود بيغيّر النتيجة عندك بس، والسيرفر بيرفضها.
- **الحسابات متطابقة على كل المتصفحات.** اللعبة ما بتستخدم `Math.sin/cos/atan2/hypot/random` (بتختلف بين المتصفحات)، بدالها نسخ محسوبة بعمليات أساسية بتطلع نفس النتيجة بالضبط.

**بصراحة للآخر:** هاد بيخلي الحل الآلي المسبق مستحيل، وبيجبر أي حل إنه يلعب **حي** إطار بإطار ضد السيرفر طول اللعبة — وهاد مشروع صعب، مش سكربت. بس لعبة مهارة بالمتصفح ما بتصير "صفر بوت" أبداً: حدا بيكتب بوت حي لسا نظرياً بيقدر. هامش النظر للأمام محدود بـ ~ثانية (نافذة ردة الفعل).

## الواجهات (API)

- `POST /api/start` → `{ token }` تذكرة موقّعة (رقم جلسة + وقت البداية).
- `POST /api/rng { token, replay, have }` → `{ from, to, seeds }` النافذة الجاية من العشوائية، بشرط إثبات البقاء حي بوقت حقيقي.
- `POST /api/verify { token, replay }` → `{ ok, png }` الصورة، بس لجولة فوز حقيقية.

## النشر الحالي: Render

اللعبة شغّالة على **https://abdalaziz4.onrender.com** (خطة مجانية، منطقة Frankfurt).

| الإعداد | القيمة |
|---|---|
| Branch | `claude/the-smuggler-challenge-shpl2j` (أي push عليه بيعمل deploy تلقائي) |
| Build Command | `cd the-smuggler && npm install` |
| Start Command | `node the-smuggler/server/node.js` |
| Environment | `SMUGGLER_SECRET` (السر)، و`NODE_VERSION=22` |

> الخطة المجانية بتنام بعد 15 دقيقة بدون زوار، وأول فتحة بعدها بتاخذ حوالي دقيقة. التذاكر ما بتتأثر بإعادة التشغيل.

## بديل: النشر المجاني على Vercel

1. ادخل على https://vercel.com وسجّل دخول بحساب GitHub.
2. اضغط **Add New → Project**، واختار الريبو `Everything-` واضغط **Import**.
3. عند **Root Directory** اضغط **Edit** واختار `the-smuggler`.
4. افتح **Environment Variables** وضيف:
   - Key: `SMUGGLER_SECRET`
   - Value: السر (64 حرف). احتفظ فيه لحالك، ولا تحطه بالريبو أبداً.
5. اضغط **Deploy**. بعد دقيقة بيطلع لك رابط مثل `https://the-smuggler-xxxx.vercel.app`، وهاد اللي بتعطيه للاعبين.

> بيشتغل كمان على أي استضافة Node: `SMUGGLER_SECRET=... npm start` (المنفذ الافتراضي 3000، وبتقدر تغيّره بـ `PORT`).

## تغيير الصورة أو الفلاج

1. اعمل سر جديد: `openssl rand -hex 32`
2. شفّر الصورة:
   ```
   SMUGGLER_SECRET=<السر> node tools/seal-trophy.mjs path/to/smuggler_trophy.png
   ```
   بيكتب `server/trophy.js` (مشفّر، وعادي ينرفع للريبو).
3. اعمل commit لـ `server/trophy.js`، وحدّث `SMUGGLER_SECRET` على Vercel، وبعدها **Redeploy**.

لا ترفع الصورة الأصلية (`.png`) ولا السر للريبو، لأن الريبو عام.

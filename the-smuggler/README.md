# THE SMUGGLER — "The Border"

لعبة استنتاج قصيرة. إنت حارس الحدود، والمسافرين بيجوا واحد واحد. في **قانون سري** بيحدد مين مهرّب، واللي يكتشف القانون ويمسك سلسلة صح بياخذ صورة الكأس من السيرفر.

**اللعب:** كل مسافر إله صفات ظاهرة (معطف، صندوق، قبعة، ختم، شارة). تضغط **SEARCH** (تفتيش) أو **PASS** (مرور). السيرفر بيقول لك صح/غلط وبيكشف إذا كان مهرّب فعلاً — فتتعلّم القانون. لازم **٨ قرارات صح متتالية** قبل **٥ أخطاء**. بعض القوانين بتعتمد على **المسافر السابق**، فهو ظاهر على الشاشة كمان.

## ليش صعبة على الـ AI؟

- **القانون مش موجود بأي مكان عند اللاعب.** مش بالـ HTML ولا بالجافاسكربت ولا بأي رد من السيرفر. السيرفر بس بيقول صح/غلط. فما في شي "تقرأه" أو "تفك تشفيره" — الطريق الوحيد هو **الاستنتاج**.
- **ما في قوة غاشمة.** كل مسافر بينحكم عليه مرة وحدة (السيرفر بيمنع إعادة محاولة نفس المسافر)، والأخطاء محدودة بـ ٥. فما تقدر تجمع بيانات كثير قبل ما تنتهي الجولة، وكل جولة جديدة قانونها جديد.
- **المحور اللي الأتمتة ضعيفة فيه:** القوانين كثير منها **علائقية** (قارن صفتين) أو **زمنية** (قارن بالمسافر السابق)، من فضاء كبير (١٨١ قانون متوازن) وغير معروف للمهاجم. استنتاج قانون مجهول من أمثلة قليلة مع ميزانية أخطاء ضيقة — هاد اللي العقل البشري أشطر فيه بكثير من الوكلاء الآليين.
- **الكأس مشفّر** (AES-256-GCM) ومفتاحه من `SMUGGLER_SECRET`، فالكود لحاله ما بيفيد.

> بصراحة: ما في بوابة ويب "مستحيلة ١٠٠٪" على AI قوي. هاي بتنقل الصعوبة لمحور الاستنتاج البشري، وبترفع العتبة كثير مقارنة بلعبة مهارة (اللي البوت أشطر فيها من الإنسان). المحاكاة: التخمين العشوائي بيخسر دايماً، وحتى حل بيعرف عيلة القوانين كاملة مش مضمون يفوز.

## الواجهات (API)

- `POST /api/start` → `{ token, goal, maxStrikes, at, prev, cur }` — يبدأ جلسة بقانون جديد، ويعطي أول مسافرَين (السابق + اللي عالبوابة).
- `POST /api/step { token, at, decision }` → `{ correct, actual, streak, strikes, done, won, at, prev, cur, png? }` — `decision` إمّا `"search"` أو `"pass"`. عند الفوز بيرجع `png` (الكأس).

الحالة محفوظة بذاكرة السيرفر لكل جلسة، فلازم عملية Node واحدة مستمرة (Render)، مش دوال serverless.

## النشر (Render)

شغّال على **https://abdalaziz4.onrender.com** (خطة مجانية، Frankfurt).

| الإعداد | القيمة |
|---|---|
| Branch | `claude/the-smuggler-challenge-shpl2j` (push = deploy تلقائي) |
| Build Command | `cd the-smuggler && npm install` |
| Start Command | `node the-smuggler/server/node.js` |
| Environment | `SMUGGLER_SECRET` (السر)، و`NODE_VERSION=22` |

> الخطة المجانية بتنام بعد ١٥ دقيقة بدون زوار، وأول فتحة بتاخذ ~دقيقة. افتح الرابط قبل بداية الـ CTF عشان يصحى.

## تغيير الصورة أو الفلاج

```
openssl rand -hex 32                                   # سر جديد
SMUGGLER_SECRET=<السر> node tools/seal-trophy.mjs trophy.png   # يكتب server/trophy.js (مشفّر، عادي ينرفع)
```
بعدها commit لـ `server/trophy.js`، وحدّث `SMUGGLER_SECRET` على Render، وRedeploy. لا ترفع الصورة الأصلية ولا السر.

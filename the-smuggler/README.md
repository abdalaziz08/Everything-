# THE SMUGGLER (نسخة السيرفر)

لعبة bullet-hell ثلاث مراحل. اللي بيهزم البوس بياخذ صورة الكأس من السيرفر.

## ليش ما في طريقة تاخذ الصورة بدون ما تلعب؟

- **الصورة مش موجودة باللعبة أبداً.** هي محفوظة على السيرفر بس، ومشفّرة بـ AES-256-GCM. المفتاح جاي من متغيّر البيئة `SMUGGLER_SECRET`، يعني الكود المنشور هون لحاله ما بيفيد بشي.
- **السيرفر ما بيصدّق المتصفح.** المتصفح بيسجّل أزرار اللاعب إطار بإطار، وبيبعث التسجيل للسيرفر. السيرفر بيعيد تشغيل اللعبة كاملة بنفس الكود (`public/sim.js`)، وما بيبعث الصورة إلا إذا البوس مات فعلاً بهاد التسجيل.
- **كل محاولة إلها seed عشوائي** بيعطيه السيرفر بتذكرة موقّعة (HMAC)، فما بتقدر تعيد استخدام تسجيل من محاولة ثانية.
- **فحص الوقت الحقيقي:** اللعبة بتمشي 60 إطار بالثانية، فإذا التسجيل أطول من الوقت اللي مرّ فعلاً من بداية المحاولة، بينرفض.
- **الغش بالمتصفح ما بيفيد.** تعديل صحة البوس أو الخلود بيغيّر النتيجة عندك بس، والسيرفر بيرفضها.
- **الحسابات متطابقة على كل المتصفحات.** اللعبة ما بتستخدم `Math.sin` و`cos` و`atan2` و`hypot` و`random`، لأنها ممكن تختلف بين المتصفحات. بدالها في نسخ محسوبة بعمليات أساسية بتطلع نفس النتيجة بالضبط بكل مكان.

الشي الوحيد اللي ما بينمنع 100% هو بوت بيلعب فعلاً وبيفوز. وهاد لعب، مش سحب للملف.

## النشر الحالي: Render

اللعبة شغّالة على **https://the-smuggler.onrender.com** (خطة مجانية، منطقة Frankfurt).

| الإعداد | القيمة |
|---|---|
| Branch | `claude/the-smuggler-challenge-shpl2j` (أي push عليه بيعمل deploy تلقائي) |
| Build Command | `cd the-smuggler && npm install` |
| Start Command | `node the-smuggler/server/node.js` |
| Environment | `SMUGGLER_SECRET` (السر)، و`NODE_VERSION=22` |

> الخطة المجانية بتنام بعد 15 دقيقة بدون زوار، وأول فتحة بعدها بتاخذ حوالي دقيقة. التذاكر ما بتتأثر بإعادة التشغيل.

## بديل: النشر المجاني على Vercel

1. ادخل على https://vercel.com وسجّل دخول بحساب GitHub.
2. اضغط **Add New → Project**، واختار الريبو `Everything-` واضغط **Import**.
3. عند **Root Directory** اضغط **Edit** واختار `the-smuggler`.
4. افتح **Environment Variables** وضيف:
   - Key: `SMUGGLER_SECRET`
   - Value: السر (64 حرف). احتفظ فيه لحالك، ولا تحطه بالريبو أبداً.
5. اضغط **Deploy**. بعد دقيقة بيطلع لك رابط مثل `https://the-smuggler-xxxx.vercel.app`، وهاد اللي بتعطيه للاعبين.

> بيشتغل كمان على أي استضافة Node: `SMUGGLER_SECRET=... npm start` (المنفذ الافتراضي 3000، وبتقدر تغيّره بـ `PORT`).

## تغيير الصورة أو الفلاج

1. اعمل سر جديد: `openssl rand -hex 32`
2. شفّر الصورة:
   ```
   SMUGGLER_SECRET=<السر> node tools/seal-trophy.mjs path/to/smuggler_trophy.png
   ```
   بيكتب `server/trophy.js` (مشفّر، وعادي ينرفع للريبو).
3. اعمل commit لـ `server/trophy.js`، وحدّث `SMUGGLER_SECRET` على Vercel، وبعدها **Redeploy**.

لا ترفع الصورة الأصلية (`.png`) ولا السر للريبو، لأن الريبو عام.

## الملفات

| الملف | شو بيعمل |
|---|---|
| `public/index.html`, `public/game.js` | اللعبة بالمتصفح: الرسم والتحكم والتسجيل والإرسال |
| `public/sim.js` | قواعد اللعبة، مشتركة بين المتصفح والسيرفر |
| `api/start.js`, `api/verify.js` | دوال Vercel |
| `server/app.js` | التذاكر وفحص التسجيل وفك تشفير الصورة |
| `server/node.js` | سيرفر Node عادي للتجربة المحلية |
| `server/trophy.js` | الصورة مشفّرة |
| `tools/seal-trophy.mjs` | تشفير صورة جديدة |
| `tests/` | الاختبارات وبوت للاختبار فقط |

## الاختبارات

```
node tests/run-tests.mjs                                   # اللعبة والسيرفر (~20 ثانية)
SMUGGLER_SECRET=<السر> node tests/e2e.mjs [trophy.png]     # متصفح حقيقي، بوت بيلعب بالوقت الحقيقي (~2 دقيقة)
BASE_URL=https://the-smuggler.onrender.com node tests/e2e.mjs [trophy.png]   # نفس الاختبار على الموقع المنشور
```
